# Support

Scrappy Forge is currently moving toward public beta.

For normal usage questions, setup problems and reproducible bugs, use GitHub Issues once you have checked the README and user guide.

Before opening an issue, include:

- operating system and architecture
- Python version
- Scrappy Forge version/commit
- the command you ran
- the smallest useful error/output
- whether the problem reproduces without third-party plugins/connectors

Please remove API keys, tokens, private URLs, customer data and other secrets from logs before posting them.

For security vulnerabilities, do **not** use a public support issue. Follow [SECURITY.md](SECURITY.md).
